# 双界行者（Dual World Walker）

基于 JavaFX Canvas 开发的单机俯视角 Roguelike 动作游戏原型。玩家在光之界与影之界之间切换：光界使用远程光弹，影界使用近战扇形斩击；只有处于同一世界的敌人与攻击才会生效。

> 文档基线：2026-09-10。项目当前已完成第 1～6 天的主要玩法闭环，并有一版简化的 Boss 跨界战斗；道具成长、商店事件、死亡结算和完整 Boss 技能仍在开发中。

## 已实现内容

- 登录、本地档案（昵称与密码摘要）、主菜单、设置、暂停与全屏切换。
- 固定 60 Hz 游戏循环；WASD/方向键移动，鼠标瞄准与左键连续攻击。
- 光界远程投射物与影界近战斩击；攻击、实体墙与相位墙均受当前房间边界约束。
- 满相位能量时以 `Tab` 切换世界；切换会寻找目标世界的安全落点、清除附近敌方弹体并播放相位脉冲。
- 按种子可复现的分支节点地图，包含入口、战斗、奖励、商店、事件和 Boss 节点；入口、战斗与 Boss 房具有不同布局，已探索地图会显示在小地图中。
- 战斗房与 Boss 房会生成同界敌人，房间清空后出口解锁；HUD 显示光/影剩余敌数和金币。
- 4 种普通敌人（灯灵、影狼、傀儡、法师）、2 种精英敌人（处刑者、鸣钟者）及 Boss「裂隙守望者」。敌人仅在同世界追击、发射攻击并造成伤害；Boss 半血后从光界转入影界。
- 敌人索敌覆盖整个房间：只要与玩家同处一房就会主动接近，不再有“站得远就一直不动”的敌人；被墙挡住视线时沿房间距离场绕行、只有看得见玩家时才开火，玩家切界后敌人重新索敌。
- 敌人不会被墙卡死：连续 2 秒既没更接近玩家、自身也没挪动，就会被挪到最近一个“还能继续推进”的合法位置（脱困只在走得到的范围内挪动，绝不隔墙搬运）；首领房的障碍物按首领身位（直径 92）留出外圈通道与间隔，避免玩家把它顶在墙角磨死。
- 「裂隙守望者」的招牌技是**短距裂隙闪现**：一旦追不上或打不到玩家（被顶在墙角、或玩家躲进它挤不进去的角落），就撕开一道裂隙出现在玩家附近的合法位置，落地优先选能直接打到玩家的点，并留 0.9 秒起手与 4 秒冷却——闪现的起终点会有可见的裂隙特效。
- 房间内容按种子只生成一次并保存在房间上：进出房间既不会重刷，也不会把没拿走的东西清空；已击败的怪物房再次进入不会重新刷怪。
- 奖励房提供金币与相位碎片，战斗房清空后出现宝箱（打开后奖励留在地面等待拾取）。
- 商店上架两件标价装备：第一次按 `E` 选中并显示价格，再按一次才确认购买；走开即自动取消选择，金币不足会有提示。
- 走到物品旁边会显示名称（回血道具明确写作「生命恢复药剂」），商店商品常显「名称 + 价格」。
- 小地图用细线表示房间连通性（当前房间可走的门用亮线标出），并用图标区分房间：`￥` 商店、`?` 事件、宝箱图标表示还有没开的宝箱、紫色圆环表示传送门；已清空的怪物房套绿框，还有东西可拿的房间点金点。
- 一局共 5 层：每层击败首领后房间里出现通往下一层的传送门，走近按 `E` 传送；进入新一层会在入口房提示「第 N 层」，HUD 常显当前层数；打通第 5 层穿过最后一道裂隙即通关。
- 敌人随层数变强：生命值每层 +25%，防御每层 +1（上限 3，且每次受击至少掉 1 点血）；金币、装备与生命跨层保留。

## 运行项目

需要 JDK 21 或更高版本，并将 `JAVA_HOME` 指向该 JDK。首次运行 Maven Wrapper 时需要联网下载 Maven 发行包。

```powershell
# Windows PowerShell
.\mvnw.cmd javafx:run

# 运行测试
.\mvnw.cmd test
```

macOS/Linux：

```bash
./mvnw javafx:run
./mvnw test
```

也可以在 IntelliJ IDEA 中以 Maven 项目打开根目录，配置 JDK 21 后运行 `com.phantomcorridor.Launcher`。

## 操作

| 操作 | 按键/方式 |
| --- | --- |
| 登录、菜单确认 | Enter 或鼠标左键 |
| 移动 | WASD 或方向键 |
| 瞄准与攻击 | 鼠标移动 / 按住左键 |
| 拾取、开宝箱、触发事件 | `E` |
| 商店购买 | `E` 选中（显示价格）→ 再按 `E` 确认；走开自动取消 |
| 切换光界与影界 | `Tab`（相位能量满值时） |
| 暂停/继续 | Esc 或 P |
| 切换全屏 | F11 或 Alt+Enter |

## 工程结构

```text
src/main/java/com/phantomcorridor
├── App.java / Launcher.java       # JavaFX 启动与场景编排
├── config/                        # 窗口、战斗、房间与设置常量
├── controller/                    # 输入、游戏循环及场景控制器
├── core/                          # 固定步长 GameLoop 与 GameState
├── model/
│   ├── GameSession.java           # 单局聚合状态
│   ├── dungeon/                   # 可复现地图生成与节点图
│   ├── room/                      # 房间布局、墙体、门禁、导航、寻路距离场与房间内容
│   ├── entity/                    # Player、Enemy 与 EnemyKind
│   ├── combat/                    # 玩家攻击、敌人 AI/攻击与命中结算
│   └── effect/                    # 世界切换与相位脉冲
├── util/                          # 碰撞、随机数、资源加载
└── view/                          # JavaFX 视图与 Canvas 渲染器

src/main/resources/com/phantomcorridor
├── sprites/                       # 玩家、投射物与怪物像素资源
├── enemies/                       # 敌人图集与素材说明
└── ui/ui.css                      # 登录/菜单/覆盖层样式
```

模型层不依赖 JavaFX；视图只读取游戏状态并绘制，控制器负责输入和场景生命周期。详细需求、实现状态和后续范围见 [《双界行者》项目需求说明书.md](<./《双界行者》项目需求说明书.md>)。

## 测试

测试覆盖玩家状态、输入、世界切换、地图生成、房间导航、房间内容与商店、层数推进与敌人成长、玩家攻击、敌人生成/伤害、敌方投射物和单局状态；其中敌人索敌一项会在若干真实种子地图上模拟 30 秒，校验每个同界敌人都能锁定玩家、主动接近并走到可以开火的位置，房间内容与层数推进则真实走门进出商店、战斗房与首领房，校验货架不会重刷或清空、击败首领后能走进传送门进入下一层。执行 `./mvnw test`（Windows 为 `.\\mvnw.cmd test`）即可运行。
